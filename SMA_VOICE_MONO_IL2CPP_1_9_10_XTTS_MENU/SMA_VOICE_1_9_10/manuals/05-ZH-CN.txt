SMA VOICE — 安装与故障报告指南（简体中文）
安装程序 1.9.10 | 语音引擎 1.9.7 | Capture 0.10.13 | AutoStart 1.4.1

1. 简介
SMA Voice 使用本地 XTTS v2 为固定对话框和浮动气泡配音。固定对话优先；被打断的气泡在仍有效时可以重新播放。支持 Windows x64、Some Modeling Agency（SMA，Unity Mono）和 Corrupted Modeling Agency（CMA，Unity IL2CPP）。独立非官方模组。压缩包不含游戏、BepInEx、翻译器、Ollama 或模型权重。下列版本为开发时使用的依赖；其他版本需验证。

2. 依赖项（文件名与下载链接见末尾）
SMA：BepInEx 5.4.23.6 x64 和 UnityGameTranslator BepInEx5 0.16.1。CMA：BepInEx 6 IL2CPP build 793 x64 和 UnityGameTranslator BepInEx6-IL2CPP 0.16.1。不要混用加载器。新环境建议 Python 3.11 x64，也可复用兼容的 XTTS 环境。新安装使用 coqui-tts 0.27.5、torch/torchaudio 2.8.0、numpy、sounddevice，选择 CPU 或 CUDA 12.8（需兼容 NVIDIA 驱动，CPU 较慢）。Mono 需要 .NET Framework 4.x C# 编译器；CMA 通过 SDK .NET 6+ 编译 net6.0，缺失时安装程序在本地安装 SDK 8。下载依赖和模型需要网络和磁盘空间。接受 XTTS 许可前请阅读 CPML。建议使用 Ollama 本地翻译，需要备用翻译时必须运行。按下方命令下载模型并保持 Ollama 运行，使用本地地址而非云端。

3. 安装顺序
1）备份游戏和模组。将 SMA Voice ZIP 完整解压至单独文件夹。关闭游戏和语音读取器。
2）运行 INSTALAR.bat。手动选择 1) SMA (Mono) 或 2) CMA (IL2CPP)，输入游戏根目录或游戏 exe。安装程序验证兼容性，不会自动改变游戏或引擎。
3） 始终显示 XTTS 菜单：1 复用已登记且可用的环境，2 选择现有 XTTS，3 创建独立的新环境且不修改旧环境，4 取消。选项 3 在缺少时通过 WinGet 安装 Python 3.11 x64，并选择 NVIDIA CUDA 或 CPU；此选择仅更新 PROCESSAMENTO。提示时阅读 CPML 许可证。CMA 缺少 .NET SDK 时会安装。
4）安装程序检查 BepInEx 与 UnityGameTranslator，仅下载缺少的指定版本，并在复制前校验 SHA-256。不覆盖已有依赖，遇冲突按提示处理。下载失败时，将下方链接中的准确 ZIP 文件原样放入 dependencies/，不要解压。CMA 尚无 interop 时，先启动游戏，等待 BepInEx/interop 生成，关闭游戏后再按 Enter。随后编译并安装两个模组 DLL。
5）单独运行 INSTALAR_OLLAMA_E_MODELO.bat：缺少 Ollama 时使用 WinGet 安装，启动本地 API，缺少 qwen3:4b-instruct 时下载（约 2.5 GB）。若没有 WinGet，从官网下载 Ollama 后再次运行 BAT。其他模型保留。在 UnityGameTranslator 中选择本地 LLM、http://127.0.0.1:11434、目标语言和 qwen3:4b-instruct。新安装默认使用 qwen3:4b-instruct；如需试用其他本地模型，在 Ollama 安装后修改翻译器及 CONFIGURACOES.txt 的 MODELO_OLLAMA（或使用 auto 跟随翻译器）。其他模型由用户自行选择，不保证性能或质量。
6）正常启动游戏，等待 SMA_VOICE_*.log 出现 READY/PRONTO，再测试两种对话。AutoStart 自动启动读取器，不要启动第二个。如果询问自定义 XTTS 模型文件夹，Enter 使用默认缓存或保留原路径，'-' 选择默认缓存。首次下载和预热可能需要时间。

4. 配置和更新
<GAME> 表示所选游戏根目录；<Documents> 为 Windows 文档文件夹。LOCAL_RUNTIME.txt 显示实际 runtime/配置档路径。CONFIGURACOES.txt 为主配置，只修改 '=' 后的值，true/false、小数点、ms 毫秒、S 秒；保存后重启游戏。MANUAL_CONFIGURACOES.txt 是葡萄牙语详细参考。BepInEx cfg 管理身份过滤和 AutoStart，不要关闭身份验证。.paths 和 instalacao.json 由安装程序管理。翻译器 config.json 控制语言与翻译。文档/SMA Voice 存放运行时、语音登记、授权 WAV、缓存、配置档与备份。更新时关闭游戏并重新安装到原根目录；保留配置、缓存和语音，补充缺失键，替换文件备份位于 runtime/backups。

5. 主要设置（不要翻译键名）
DELAY_CAIXA_NORMAL_MS / FALLBACK_CAIXA_NORMAL_MS 与 DELAY_BALAO_FLUTUANTE_MS / FALLBACK_BALAO_FLUTUANTE_MS：分别等待稳定文本/翻译；INTERVALO_CAPTURA_MS / DEDUP_CAPTURA_MS：采集间隔和去重窗口。
BUFFER_INICIAL_MS / BUFFER_CAIXA_NORMAL_MS：音频缓冲，断音时增大。MODO_REPRODUCAO=adaptive/stream/stable（完整语句）；INICIO_CAIXA_POR_SEGMENTO / INICIO_BALAO_POR_SEGMENTO：已验证片段开始播放。保持 PROTEGER_AUDIO_MONO 和 PROTEGER_AUDIO_IL2CPP=true。QUALIDADE_VOZ=original/consistent/expressive；VELOCIDADE_VOZ=1.0 正常；CACHE_AUDIO、CHUNK_XTTS、PAUSA_ENTRE_FRASES_MS、LATENCIA_AUDIO 调节缓存和播放。
PROCESSAMENTO=auto/cpu/cuda；DISPOSITIVO_AUDIO=auto 或设备索引；AQUECIMENTO=true；VOZ_PADRAO 选择内置声音。IDIOMA=auto 跟随翻译器，或 pt/en/es/ru/zh-cn/ja/fr；IDIOMA_ORIGEM=auto。TRADUCAO=true、MODELO_OLLAMA=auto 或已安装模型、TIMEOUT_TRADUCAO_S=25。关闭翻译可能使其他语言的对话静音。
PRIORIDADE_CAIXA_FIXA=true、IDADE_MAX_CAIXA_FIXA_S=45、IDADE_MAX_EVENTO_S=20 为推荐默认值。INTERVALO_FILA_MS / DEDUP_FILA_MS 控制轮询和去重，旧场景语音丢弃。ENABLE_CMA_FIXED_BOX / ENABLE_CMA_BARK / ENABLE_MONO_BARK_RECOVERY 控制专用路径，保持 true。ENABLE_LOG、ENABLE_INSPECTOR=true 重启后启用诊断。

6. 在 GITHUB ISSUES 报告问题
启用日志和检查器，复现问题，尽可能正常退出。提交同一会话的三份报告：
A）BepInEx 从启动至错误的完整 CMD 输出，保存为 TXT；或完整会话的 BepInEx/LogOutput.log 或 LogOutput.txt。不要仅提交末尾几行或截图。无控制台时使用完整日志。
B）在游戏根目录运行 SMA_VERIFICAR.bat，检查文件、哈希、路径、配置、XTTS 导入和音频设备，不修复或合成。提交 SMA_VERIFICACAO.txt。若 Python 缺失导致无法写 TXT，复制完整 CMD。
C）运行 SMA_DIAGNOSTICO.bat，选 1 收集完整模组日志。采集故障选 2（游戏开启且固定对话可见），立即 Alt+Tab 回到游戏。10 秒后尝试采集 5 次快照，将本次采集加入根目录 DIAGNOSTICO_SMA_VOICE.txt。提交该 TXT，按要求附 SMA_INSPECTOR_FOCO_*.txt。若没有日志，启用 ENABLE_LOG 再复现。不会自动上传。
Issue 请说明 SMA Voice 版本、游戏/版本、backend、BepInEx、翻译器、Python/XTTS、Windows/GPU、目标语言、复现步骤、预期与实际结果。若安装失败且 BAT 未创建，提交 INSTALAR.bat 完整 CMD。公开前检查并删除用户名、私人路径、令牌、API 密钥，但保留技术错误信息。不要上传存档、角色卡、缓存、WAV、模型权重、游戏 DLL 或含凭据的 config.json。Issues 可能公开。

7. 许可证
独立模组。BepInEx、Harmony/Il2CppInterop、UnityGameTranslator、Python、PyTorch、Ollama、Qwen 和 XTTS 各自保留许可证。XTTS v2 使用 CPML，不要假定允许商业使用或再分发。仅使用有权使用的游戏、模型和声音，亲自接受许可证。压缩包不再分发依赖或恢复的旧 DLL。SMA Voice 许可请在发布后的仓库查看。

注意：翻译器的目标语言优先于 IDIOMA。新安装默认 MODELO_OLLAMA=qwen3:4b-instruct；更新保留原有设置（包括 auto）。
