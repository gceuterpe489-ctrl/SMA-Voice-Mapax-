SMA VOICE — INSTALLATION & SUPPORT GUIDE (ENGLISH)
Installer 1.9.9 | Voice engine 1.9.7 | Capture 0.10.13 | AutoStart 1.4.1

1. ABOUT
SMA Voice adds local XTTS v2 speech to fixed dialogue boxes and floating bubbles. Fixed dialogue has priority; interrupted bubbles can wait and restart if still valid. Windows x64, Some Modeling Agency (SMA, Unity Mono) and Corrupted Modeling Agency (CMA, Unity IL2CPP). Independent, unofficial mod. Games, BepInEx, translator, Ollama and model weights are not included. The versions below are the tested dependency set; other game/loader versions require testing.

2. DEPENDENCIES — exact downloads and filenames at the end
SMA: BepInEx 5.4.23.6 x64 and UnityGameTranslator BepInEx5 0.16.1 only. CMA: BepInEx 6 IL2CPP build 793 x64 and UnityGameTranslator BepInEx6-IL2CPP 0.16.1 only. Never mix the loaders. Use Python 3.11 x64 for a fresh environment, or reuse a compatible existing XTTS environment. Fresh installation uses coqui-tts 0.27.5, torch/torchaudio 2.8.0, numpy and sounddevice with CPU or CUDA 12.8 (compatible NVIDIA driver; CPU is slower). Mono needs the .NET Framework 4.x C# compiler. CMA builds for net6.0 using SDK .NET 6+; if missing, the installer installs SDK 8 locally. Internet and disk space are needed for dependency/model downloads. Read the XTTS CPML license before accepting. Ollama is recommended for local translation and required when fallback translation is needed; pull the model listed below and keep Ollama running. Use the local endpoint, not cloud.

3. INSTALL IN THIS ORDER
1) Back up the game and mods. Extract the entire SMA Voice ZIP into a separate folder. Close the game and any voice reader.
2) Run INSTALAR.bat. Choose 1) SMA (Mono) or 2) CMA (IL2CPP). Enter the game root or its executable. The game and engine are selected manually; the installer validates the selection and never changes it.
3) A working previously registered XTTS environment is reused. Otherwise select 1 for an existing XTTS environment or 2 to create one (Python 3.11 x64 via WinGet if missing, dedicated venv, NVIDIA CUDA or CPU). Read the CPML license when prompted. The .NET SDK for CMA is installed if missing.
4) The installer checks BepInEx and UnityGameTranslator, downloads only missing reference dependencies and verifies SHA-256 before copying. Existing dependencies are not overwritten; resolve any conflicts reported. If downloads fail, place the exact ZIPs from the links below, unextracted, in dependencies/. For CMA without interop, launch the game, wait for BepInEx/interop and close it before pressing Enter. Both mod DLLs are built and installed.
5) Run INSTALAR_OLLAMA_E_MODELO.bat separately to install Ollama via WinGet if absent, start the local API and pull qwen3:4b-instruct (~2.5 GB) only if missing. If WinGet is unavailable, install Ollama from its official website and run the BAT again. Other models are preserved. In UnityGameTranslator select local LLM, http://127.0.0.1:11434, target language and qwen3:4b-instruct. New installations default to qwen3:4b-instruct; to try another local model, install it in Ollama and select it in both the translator and MODELO_OLLAMA in CONFIGURACOES.txt (or use auto to follow the translator). Alternative models are the user's choice; performance and quality are not guaranteed.
6) Launch normally. Wait for READY/PRONTO in SMA_VOICE_*.log and test both kinds of dialogue. AutoStart starts the reader; do not start another. If prompted for a custom XTTS model folder, Enter uses the default cache or retains the previous folder; '-' selects default cache. Initial downloads and warm-up can take time.

4. SETTINGS AND UPDATES
<GAME> means the chosen game root; <Documents> is the Windows Documents folder, including redirected folders. LOCAL_RUNTIME.txt gives the exact runtime/profile location. Edit values after '=' in CONFIGURACOES.txt only: true/false, dot decimals, ms in milliseconds, S in seconds. Restart after edits. MANUAL_CONFIGURACOES.txt is the detailed Portuguese reference. BepInEx cfg files govern capture filters and AutoStart; keep speaker-identity filters intact. .paths and instalacao.json are installer-managed. Translator config.json controls translation and language. Documents/SMA Voice contains runtime, registered voices, authorized WAVs, cache, profiles and backups. To update, close the game, run installer for the same root. Existing preferences, cache and voice data are retained; missing keys are added. Replaced files are backed up under runtime/backups.

5. MAIN CONFIGURATION (do not translate key names)
DELAY_CAIXA_NORMAL_MS / FALLBACK_CAIXA_NORMAL_MS and DELAY_BALAO_FLUTUANTE_MS / FALLBACK_BALAO_FLUTUANTE_MS: separate stable text/translation waits. INTERVALO_CAPTURA_MS / DEDUP_CAPTURA_MS: capture interval and duplicate window.
BUFFER_INICIAL_MS / BUFFER_CAIXA_NORMAL_MS: increase if audio cuts. MODO_REPRODUCAO=adaptive, stream or stable (whole utterance); INICIO_CAIXA_POR_SEGMENTO / INICIO_BALAO_POR_SEGMENTO enable validated segment starts. Keep PROTEGER_AUDIO_MONO and PROTEGER_AUDIO_IL2CPP=true. QUALIDADE_VOZ=original/consistent/expressive; VELOCIDADE_VOZ=1.0 normal; CACHE_AUDIO, CHUNK_XTTS, PAUSA_ENTRE_FRASES_MS, LATENCIA_AUDIO tune playback/cache.
PROCESSAMENTO=auto/cpu/cuda; DISPOSITIVO_AUDIO=auto or device index; AQUECIMENTO=true; VOZ_PADRAO selects built-in voice. IDIOMA=auto follows translator or pt/en/es/ru/zh-cn/ja/fr; IDIOMA_ORIGEM=auto. TRADUCAO=true, MODELO_OLLAMA=auto or installed model, TIMEOUT_TRADUCAO_S=25; disabling translation can leave mismatched-language dialogue silent.
PRIORIDADE_CAIXA_FIXA=true, IDADE_MAX_CAIXA_FIXA_S=45, IDADE_MAX_EVENTO_S=20 are recommended defaults. INTERVALO_FILA_MS / DEDUP_FILA_MS control polling and duplicates. Prior-scene speech is discarded. ENABLE_CMA_FIXED_BOX / ENABLE_CMA_BARK and ENABLE_MONO_BARK_RECOVERY control specific routes; keep true. ENABLE_LOG and ENABLE_INSPECTOR=true enable diagnostics after restart.

6. REPORT A BUG VIA GITHUB ISSUES
Keep logging/inspector enabled, reproduce, and close normally if possible. Attach THREE reports from the same session:
A) COMPLETE BepInEx command prompt output from startup to error, saved as TXT, or BepInEx/LogOutput.log or LogOutput.txt if it contains the entire session. Not just the last lines or a screenshot. If no console, use full log.
B) Run SMA_VERIFICAR.bat at the game root. Checks files, hashes, paths, config, XTTS imports and audio devices; no repair/synthesis. Attach SMA_VERIFICACAO.txt. If Python is missing and no TXT can be written, copy the entire command output.
C) Run SMA_DIAGNOSTICO.bat, choose 1 to collect the full mod session log. For capture issues choose 2 WHILE GAME IS OPEN with fixed dialogue visible, then immediately Alt+Tab back. After 10 seconds it attempts 5 snapshots and includes this collection in DIAGNOSTICO_SMA_VOICE.txt at game root. Attach that TXT, and SMA_INSPECTOR_FOCO_*.txt if requested. If no mod log exists enable ENABLE_LOG and reproduce. Nothing is uploaded automatically.
In the issue include SMA Voice version, game/version, backend, BepInEx, translator, Python/XTTS, Windows/GPU, target language, reproduction steps, expected/actual result. If setup fails before BATs exist, attach the entire INSTALAR.bat console. Review/redact usernames, private paths, API tokens and keys without removing technical error lines. Do not attach saves, character cards, cache, WAVs, model weights, game DLLs or translator config.json containing credentials. Issues may be public.
